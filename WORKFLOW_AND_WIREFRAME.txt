Project Work Flow + Folder Structure + Technical Wireframe (DurgBhumi Redesign)

====================================
1) PROJECT WORKFLOW (Delivery Plan)
====================================

Phase A — Discovery & Spec
1. Confirm site goals
   - Primary: brand + luxury resort marketing
   - Primary conversion: “Quick Enquiry” form + “Brochure” download
   - Secondary: accommodation exploration + gallery engagement
2. Gather content sources
   - Text: JSON in src/data/*.json (hero, about, rooms, etc.)
   - Images: public/images/... (hero, dining, gallery, etc.)
   - Documents: public/broucher/*.pdf
3. SEO baseline checklist
   - Metadata (title/description), OG/Twitter
   - Canonical URLs
   - JSON-LD schema (LodgingBusiness)

Phase B — Architecture Setup (Next.js)
4. Decide route structure (App Router)
   - / (landing page sections)
   - /about
   - /accommodation (anchor-based interaction)
   - /policies
   - /api/contact (form submission)
5. Define UI component boundaries
   - Layout: src/app/layout.tsx
   - Page sections: src/components/* (Hero, Property, Gallery, etc.)
   - Data: src/data/*.json and src/lib/data.ts

Phase C — Build UI (Marketing Sections)
6. Implement hero & navigation
   - Navbar uses hash links (#home/#about/#stay/...)
   - Hero uses hero.json slides and Framer Motion transitions
7. Implement content sections with consistent motion
   - Ethos, Property, CuratedStays, InfinityPool, Amenities, Dining,
     EventsHighlights, Gallery, NatureHighlights, NearbyAttractions
8. Implement engagement systems
   - Gallery modal lightbox + scroll-driven desktop horizontal gallery
   - FloatingEnquiry drawer (desktop vertical tab + mobile floating button)

Phase D — Content Pages
9. About page
   - Reads src/data/about.json
   - Alternating image/text chapters with Framer Motion reveal
10. Policies page
   - Text-first layout with cards/tables

Phase E — Backend / API
11. Contact enquiry API
   - Endpoint: src/app/api/contact/route.ts
   - Uses nodemailer + SMTP credentials from environment

Phase F — Quality Gates
12. Lint + build + typecheck
   - npm run lint
   - npm run build
13. Accessibility + performance checks
   - Ensure Image uses next/image correctly
   - Ensure modal locks scroll correctly
   - Ensure forms validate client-side

Phase G — Deployment
14. Build and deploy to Vercel/hosting
   - Ensure env vars: SMTP_USER, SMTP_PASS, NEXT_PUBLIC_SITE_URL

3) TECHNICAL WIREFRAME (Wireframe + Component Map)
====================================

Legend:
- [Section] = visual section
- (Component) = React/Next component file
- -> = data source

3.1 Global Layout (Root)
--------------------------------
Route: src/app/layout.tsx

<html>
  <body>
    <script type="application/ld+json"> (JSON-LD LodgingBusiness)
    <Preloader />
    <Navbar />

    <main>
      {children} (route content)
    </main>

    <ScrollToTop />
    <Footer />
    <FloatingEnquiry />
  </body>
</html>

3.2 Landing Page (Home) Wireframe
--------------------------------
Route: src/app/page.tsx

[Hero] (Hero.tsx)
- Background: hero.json slides -> Next/Image
- Foreground: logo + tagline + CTA button -> link to #stay
- Scroll indicator: animated arrow

[Ethos] (Ethos.tsx)
- Brand values cards + motion reveals

[Property Overview] (Property.tsx)
- Section header
- Two-column layout
  - Left: image + intro text -> propertyoverview.json
  - Right: features grid -> propertyoverview.json

[Curated Stays / Accommodation Preview] (CuratedStays.tsx)
- Desktop (lg+): sticky full-height experience
  - Background layers per room
  - Foreground image stack
  - Text slides synchronized with scroll progress
- Mobile: stacked cards per room

[Infinity Pool] (InfinityPool.tsx)
- Media + feature highlights

[Amenities] (Amenities.tsx)
- Amenity tiles from amenities.json

[Dining] (Dining.tsx)
- Dining highlights from diningHighlights.json

[Events Highlights] (EventsHighlights.tsx)
- Event image/text cards

[Gallery] (Gallery.tsx)
- Mobile: masonry columns using CSS columns
- Desktop: sticky horizontal scroll effect driven by scrollYProgress
- Modal/lightbox
  - Next/Prev navigation
  - Body scroll locked while modal open

[Nature Highlights] (NatureHighlights.tsx)
- Scenic tiles

[Nearby Attractions] (NearbyAttractions.tsx)
- Cards/links to attractions -> attractions.json

Conversion UI (persistent)
- FloatingEnquiry (FloatingEnquiry.tsx)
  - Trigger: desktop vertical tab + mobile bottom-right button
  - Drawer: enquiry form
  - Submit -> POST /api/contact

Footer
- Contact Us + Map iframe + phone/mail links

3.3 About Page Wireframe
--------------------------------
Route: /about (src/app/about/page.tsx)

[Hero Banner]
- “Our Story” label
- H1 = about.page_title -> about.json

[Chapters (repeating blocks)]
For each section in about.sections:
- Left image (optional) + right text (or reversed for alternating chapters)
- Motion: blur+translate reveals
- If points exist -> rendered as bullet list
- Else -> rendered paragraph content

[Footer Quote]
- about.footer_quote

3.4 Policies Page Wireframe
--------------------------------
Route: /policies (src/app/policies/page.tsx)

[Header]
- “Resort Policies”

[Policy Cards]
- Meal Plans & Tariffs (cards)
- Pet Policy (bullets)
- Booking & Payment (sections)
- Cancellation & Refund (tables + cards)

3.5 Accommodation Page Wireframe (anchor-based)
--------------------------------
Route: /accommodation (based on existing components)

- CuratedStays provides scroll/CTA to /accommodation#<room-name>
- Expected behavior:
  - accommodation page uses room data (rooms.json)
  - each room has anchor IDs matching CTA

3.6 API Wireframe (Enquiry form)
--------------------------------
POST /api/contact (src/app/api/contact/route.ts)

Request JSON:
{
  name: string,
  email: string,
  phone: string,
  subject: string,
  message: string
}

Server:
- Validate required fields (name/email/message)
- Create nodemailer transporter with SMTP_USER/SMTP_PASS
- Send email:
  - to: booking@durgbhumi.com
  - replyTo: user email
- Return:
  { success: true } or { success: false, message }

   - Ensure Navbar hash targets exist
